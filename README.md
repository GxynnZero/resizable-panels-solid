# resizable-panels-solid

[![pnpm](https://img.shields.io/badge/maintained%20with-pnpm-cc00ff.svg?style=for-the-badge&logo=pnpm)](https://pnpm.io/)

Flexible and accessible resizable panel layouts for SolidJS.

## Quick start

Install it:

```bash
npm i resizable-panels-solid
# or
yarn add resizable-panels-solid
# or
pnpm add resizable-panels-solid
```

Use it:

```tsx
import { Panel, PanelGroup, ResizeHandle } from 'resizable-panels-solid'
```
